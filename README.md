# Marcin Fracz — personal website

A personal site styled like a computer desktop: a dock, draggable windows,
widgets and sticky notes. Plain HTML, CSS and vanilla JavaScript. No
framework, no build step. Open `index.html` by double-clicking, or host it
on GitHub Pages.

## Files

- `index.html`
- `css/styles.css`
- `js/app.js`
- `content/content.js` — all site text as one global variable
- `assets/` — profile photo, wallpaper, sizzle reel, resume PDF
